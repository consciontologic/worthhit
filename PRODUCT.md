# Worthhit

Worthhit estimates what a used product may reasonably be worth, using current comparable evidence and transparent uncertainty. The same valuation serves anyone checking the product, without separate buying or selling modes. The primary action is checking a product, followed by reviewing its evidence and uncertainty. Phone users progress through details, evidence and estimate; tablet users alternate compact edit/result panes; desktop users compare facts and results side by side. Drafts persist across layout changes and locally across reloads. API credentials remain in memory.

No server or remote database. The browser calls OpenRouter using the user's key. Live web research is an explicit paid-search opt-in; supplied evidence needs no search fees. Unsupported or weak evidence yields questions, never invented prices. The product refuses prohibited goods and treats listing text as untrusted data. No promise of a guaranteed sale price or automatic authenticity verification.

Visual brief: editorial neo-brutalism with graphite, warm neutral surfaces, sharp rules and restrained lime accents. Serious, useful and approachable. Square panels, near-square controls, strong typography; hard shadows reserved for evidence-admitted price ranges. No photos, people, animals, object illustrations, gradients or heavy purple. Light and dark variants share hierarchy and contrast. The interface is a working tool, not a marketing landing page.

Eight languages follow the browser or an explicit user override; Arabic mirrors the flow. UI language never changes the canonical currency, condition or evidence quotes. Theme and language changes retain the current draft and result.
