# Worthhit

Worthhit estimates what a used product may reasonably be worth from product, currency and condition, with optional notes, images or video. The same valuation serves anyone checking the product, without separate buying or selling modes. Users submit a single form and review a fair-price estimate with clear uncertainty. Phone and tablet users alternate input/result panes; desktop users compare the form and result side by side. Drafts persist across layout changes and locally across reloads. API credentials and attached files remain in memory; files clear on reload.

No server or remote database. The browser calls OpenRouter using the user's key. A homepage Models dropdown shows free models, usable text/image/video capabilities and limits; media buttons follow the chosen model. Live web research is an explicit paid-search opt-in. The app calculates a range locally from admitted recent sales, or from bounded model assumptions with an explicit unverified-estimate label. It never invents comparable evidence. When neither is meaningful, it explains the missing context. The product refuses prohibited goods and treats notes, media and listing text as untrusted data. No promise of a guaranteed sale price or automatic authenticity verification.

Visual brief: editorial neo-brutalism with graphite, warm neutral surfaces, sharp rules and restrained lime accents. Serious, useful and approachable. Square panels, near-square controls, strong typography; hard shadows reserved for result emphasis. No decorative stock photos, people, animals, object illustrations, gradients or heavy purple; user attachments are functional product inputs. Light and dark variants share hierarchy and contrast. The interface is a working tool, not a marketing landing page.

Eight languages follow the browser or an explicit user override; Arabic mirrors the flow. UI language never changes the canonical currency, condition or evidence quotes. Theme and language changes retain the current draft and result.
