# Worthit

Worthit helps everyday buyers and sellers decide what a used item may reasonably sell for, using current comparable evidence and transparent uncertainty. The primary action is checking a product, followed by reviewing the evidence and planning a fair negotiation. Phone users progress through details, evidence and estimate; tablet users alternate compact edit/result panes; desktop users compare facts and results side by side. Drafts persist across layout changes and locally across reloads. API credentials remain in memory.

No server or remote database. The browser calls OpenRouter using the user's key. Live web research is an explicit paid-search opt-in; supplied evidence needs no search fees. Unsupported or weak evidence yields questions, never invented prices. The product refuses prohibited goods and treats listing text as untrusted data. No promise of a guaranteed sale price or automatic authenticity verification.

Visual brief: neo-brutalism, warm paper, ink, acid lime, yellow and coral. Playful but financially calm. Bold typography and borders, offset shadows, restrained abstract geometry; no heavy purple. The interface is a working tool, not a marketing landing page.
